# arnetweaks-styles

Texture-Styles für die Minecraft-Mod **[ArneTweaks](https://github.com/ArneLovesClaude/ArneTweaks)**.

Die Mod lädt diese Dateien automatisch, wenn ein Spieler eine Kategorie öffnet oder einen Style auswählt.
Man muss hier nichts selbst herunterladen.

- Die Dateien liegen unter **[Releases](https://github.com/ArneLovesClaude/arnetweaks-styles/releases/latest)**.
- `index.json` listet pro Kategorie eine ZIP-Datei mit SHA-256-Prüfsumme.
- Große Kategorien (Himmel) haben pro Style ein eigenes ZIP.

## Rechte

Die Texturen stammen aus Texture-Packs verschiedener Ersteller und gehören ihnen.
Wenn du Ersteller eines Packs bist und es hier nicht haben möchtest, öffne bitte ein
[Issue](https://github.com/ArneLovesClaude/arnetweaks-styles/issues). Es wird dann entfernt.
